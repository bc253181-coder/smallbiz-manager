# 09 · 条形码扫码 · 设计

> 阶段 13。

## 1. 现状与问题

- 商品已经有「条码」字段，搜索框也能按条码搜，但**扫码枪用不了**：扫码枪像键盘一样极快地输入条码再按回车，而现在的搜索要等 0.25 秒才查询，回车时结果还没出来，什么都不会发生。
- 同一个商品再扫一次，应该是**数量 +1**，现在已添加的商品会从搜索结果里消失，扫第二次提示"没有找到"。
- 手机没有扫码枪，需要**用摄像头扫**。
- 条码没有唯一约束：两个商品填了同一个条码时，扫码不知道该选哪个。
- 很多小店的商品（散装、自制、无码货）**没有条码**，需要能自己生成并打印标签。

## 2. 功能

| # | 功能 | 说明 |
|---|---|---|
| B1 | **扫码枪** | 开单、采购、打印标签页的商品框（库存页的盘点/入库/出库通过扫码搜索定位商品）：扫码枪输入后回车，**立即**按条码（其次 SKU）精确查找并添加；已在单里的商品数量 +1；找不到时提示"没有条码为 xxx 的商品"，并提供「用这个条码新建商品」 |
| B2 | **手机摄像头扫码** | 商品框旁边的「扫码」按钮打开摄像头；识别成功震动一下并自动添加，可连续扫多个；支持 EAN-13、EAN-8、UPC、Code 128、QR 码 |
| B3 | **扫码查商品** | 商品列表、库存页的搜索框也支持扫码，扫到唯一商品直接打开详情 |
| B4 | **条码唯一** | 同一店铺内条码不能重复（已删除的商品不算）。保存商品、导入时重复会提示"条码已被「xx」使用" |
| B5 | **生成店内码** | 没有条码的商品可一键生成 13 位店内码（以 `20` 开头，这是国际上留给店内自用的号段，不会和商品包装上的条码冲突） |
| B6 | **打印条码标签** | 在打印标签页搜索或扫码添加商品（也可从商品详情直接进入）、设置张数 → 生成标签页面（商品名、价格、条码），用浏览器打印；预设几种常见标签纸尺寸（40×30mm 标签机、A4 不干胶 3×8） |

## 3. 套餐划分（2026-11-09 已确认）

| 功能 | 建议套餐 | 理由 |
|---|---|---|
| 扫码枪、摄像头扫码、条码唯一、店内码 | **所有套餐** | 开单是最基本的操作，扫码让免费用户也觉得"好用"，更愿意留下来 |
| 批量打印条码标签 | **标准版** | 有一定规模的店才会批量打标签，适合作为升级理由 |

## 4. 技术方案

- **扫码枪识别**：商品框按下回车时，如果输入内容像条码（只有数字/字母、长度 ≥ 6），直接调用 `GET /products/lookup?code=` 精确查找，不等搜索结果
- **摄像头**：优先使用浏览器自带的 BarcodeDetector（安卓 Chrome 等）；不支持时（iPhone Safari）按需加载 ZXing 识别库，只在点「扫码」时才下载，不影响首屏速度。摄像头需要 HTTPS（正式部署已有）
- **条码唯一**：Flyway V12 加一个"未删除商品的条码"生成列并建唯一索引；迁移时对现有重复条码保留最早的商品、其余清空（迁移不单独记录日志；被清空的商品条码为空，商户可重新填写或生成店内码）
- **店内码**：`20` + 10 位店铺内序号 + 1 位校验位（EAN-13 标准算法），用现有单号序列生成，保证不重复
- **标签打印**：前端用 JsBarcode 生成 SVG 条码，打印样式用 `@page` 控制纸张尺寸

## 5. 接口

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/products/lookup?code=` | 按条码精确查找，其次 SKU；返回商品或 404 | 成员 |
| POST | `/products/barcodes/generate` | 生成一个未被使用的店内码（只返回号码，保存商品时写入；新建和编辑商品都能用） | 店主/管理员 |
| — | 商品新增/修改/导入 | 条码重复返回 409 `BARCODE_EXISTS` | — |

## 6. 页面改动

| 页面 | 改动 |
|---|---|
| 开单 / 采购单 / 盘点 / 入库出库 | 商品框支持扫码枪；旁边「扫码」按钮（手机显示）；重复扫同一商品数量 +1；找不到时可用该条码新建商品 |
| 商品新增/编辑 | 条码输入框旁「扫码」「生成店内码」 |
| 商品列表 / 商品详情 | 搜索框支持扫码（扫到唯一商品直接打开详情）；「打印标签」入口 |
| 打印标签页 | 选择标签尺寸、每个商品张数、是否显示价格；预览 → 打印 |

## 7. 测试计划

- 后端：按条码 / SKU 精确查找；其他店铺的条码查不到（404）；条码重复保存被拒；删除商品后条码可以再用；店内码校验位正确且不重复；迁移对已有重复条码的处理
- 前端 / 端到端：模拟扫码枪（快速输入 + 回车）在开单页添加商品，再扫一次数量变 2；扫不存在的条码提示并可新建；生成店内码；打印标签页显示正确的条码图形
- 摄像头扫码用真机手动验证（自动化测试无法使用摄像头）

## 8. 本阶段不做

称重条码（电子秤打印的带重量/金额的条码）、商品多条码（一个商品多个包装条码）、蓝牙打印机直连、收银小票打印。
