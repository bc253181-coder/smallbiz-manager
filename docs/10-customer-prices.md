# 10 · 客户协议价 · 设计

> 阶段 14。专业版权益中的"客户协议价"（见 01 文档第 4 节）。

## 1. 要解决的问题

批发生意里，老客户经常有**谈好的固定价格**：同一款数据线，张三拿 7.5 元、李四拿 8 元，都和统一的批发价（9 元）不一样。现在开单时只能每次手动改单价，容易记错、改漏，也查不到"给这个客户的价格是多少"。

## 2. 业务规则

| # | 规则 | 说明 |
|---|---|---|
| P1 | **一个客户 + 一个商品 = 一个协议价** | 重复设置就是修改；可以删除 |
| P2 | **开单时价格的优先顺序** | 协议价 → 客户默认价格（零售 / 批发）→ 零售价。开单人仍可手动改单价（与现在一样） |
| P3 | **记录价格来源** | 每一行销售明细记录单价来自：零售价 / 批发价 / 协议价 / 手动修改，以后能查"这张单是不是按协议价卖的" |
| P4 | **低于成本提醒** | 协议价低于当前进货成本时，设置和开单页面都会提醒（允许保存，有时就是要亏本冲量） |
| P5 | **权限** | 店主、管理员可以设置；店员开单时**自动带出**协议价，但看不到其他客户的协议价列表、不能修改 |
| P6 | **套餐** | 专业版功能。到期后：协议价数据保留，但开单不再自动带出（回到零售 / 批发价）；页面显示为只读并提示续费 |
| P7 | **批量设置** | 支持 Excel 导入（沿用阶段 12 的导入流程：模板 → 预检 → 导入），按客户电话 / 名称 + 商品 SKU / 条码匹配 |
| P8 | 商品删除 / 客户删除 | 协议价随之失效（不显示、不带出），数据保留 |

## 3. 套餐划分（需要你确认）

| 功能 | 建议套餐 | 理由 |
|---|---|---|
| 客户协议价（设置、开单自动带出、导入） | **专业版** | 已公布的专业版权益；批发价（统一的批发价）仍是标准版，不变 |

## 4. 数据库（Flyway V13）

**customer_prices**
| 字段 | 类型 | 说明 |
|---|---|---|
| id, tenant_id | | |
| customer_id | BIGINT FK | |
| product_id | BIGINT FK | |
| price | DECIMAL(14,2) | ≥ 0 |
| notes | VARCHAR(200) | 例如"2026 年框架协议" |
| created_by, updated_by, created_at, updated_at, version | | |

唯一约束 `(tenant_id, customer_id, product_id)`；索引 `(tenant_id, product_id)`。

**sales_order_items** 新增 `price_source VARCHAR(20)`：RETAIL / WHOLESALE / CONTRACT / MANUAL（已有数据按订单的价格类型回填，无法区分是否手改）。

## 5. 接口

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/customers/{id}/prices?q=` | 该客户的协议价列表（商品、零售价、批发价、协议价、比批发价低多少、成本提醒） | 店主/管理员 |
| PUT | `/customers/{id}/prices/{productId}` | `{price, notes}` 新增或修改 | 店主/管理员 |
| DELETE | `/customers/{id}/prices/{productId}` | 删除 | 店主/管理员 |
| GET | `/products/{id}/customer-prices` | 哪些客户对这个商品有协议价 | 店主/管理员 |
| GET | `/customers/{id}/prices/quote?productIds=` | 开单用：这些商品对该客户的实际价格和来源 | 成员 |
| POST | `/imports/customer-prices` | 批量导入（模板列：客户电话、客户名称、商品 SKU、商品条码、协议价、备注） | 店主/管理员 |
| POST | `/sales-orders` | 单价留空时按 P2 自动取价；后端记录价格来源 | 成员 |

## 6. 页面

| 页面 | 改动 |
|---|---|
| 客户详情 | 新增「协议价」卡片：列表（商品、批发价、协议价、优惠幅度）、搜索或扫码添加商品、行内修改、删除、导入 |
| 商品详情 | 新增「客户协议价」卡片：哪些客户有特价 |
| 开单 | 选客户后，有协议价的商品自动用协议价，单价旁显示「协议价」标签；手动改价后显示「已改价」；换客户时重新取价（手动改过的行不变） |
| 销售单详情 | 每行显示价格来源 |

## 7. 测试计划

- 优先顺序：同一商品，有协议价的客户取协议价；没有的取批发 / 零售价；手动传单价时记录为 MANUAL
- 设置、修改、删除；同一客户 + 商品只有一条（并发设置不重复）
- 店员：开单能带出协议价，读取协议价列表 403、修改 403
- 套餐：标准版设置 403；专业版到期后开单不再使用协议价、数据保留
- 低于成本的提醒字段正确
- 店铺隔离：其他店铺的客户 / 商品 404
- 导入：按电话 / SKU 匹配、找不到的客户或商品报错到行、整批回滚
- 端到端：给客户 A 设协议价 7.5 → 为 A 开单单价自动 7.5、标「协议价」→ 为客户 B 开单仍是批发价 9 → 销售单详情显示价格来源

## 8. 本阶段不做

协议价有效期（起止日期）、按数量阶梯价、按客户等级 / 分组统一折扣、按分类批量打折、促销活动价。
