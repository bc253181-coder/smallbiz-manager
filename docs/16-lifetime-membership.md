# 16 · 普通会员 + 高级永久会员 · 设计

> 阶段 20。依据你提供的《会员功能次数限制与权限管理方案》，落到 SmallBiz 的具体功能上。
> **这会改变收费模式**：从「标准版 / 专业版按月、按年订阅」改为「普通会员免费 + 高级永久会员 ¥29.9 一次性付款」。第 7 节有几项需要你决定。

## 1. 会员等级

| 等级 | 价格 | 说明 |
|---|---|---|
| 普通会员（Free） | 免费 | 按次数限制体验，见第 2 节 |
| 高级永久会员（Lifetime Premium） | ¥29.9 一次性付款（马币价格见第 7 节） | 解锁全部功能，永久有效，不自动续费 |

- **会员跟着账号走**：用户买一次，他名下的所有店铺（包括以后新开的）都是高级会员；店里的员工使用该店铺时享有同样的功能
- 高级会员的功能 = 现在专业版的全部功能（以及以后新增的高级功能）

## 2. 方案中的各项对应到 SmallBiz

| 方案中的项目 | 在 SmallBiz 中是 | 普通会员（方案初始值） | 计数方式 |
|---|---|---|---|
| 创建项目 | **新开店铺** | 最多 2 个 | 按账号累计；成功创建才计数 |
| 创建新内容 | **新建商品**（含 Excel 导入的商品） | 最多 3 个 | 按账号累计；**删除商品不返还** |
| 高级工具 | 客户、供应商、采购、批发价、赊账收款、员工、多仓库、协议价 | 不可用 | — |
| 高级模板 | 打印条码标签（标签纸模板） | 不可用 | — |
| 导出完整报告 | 导出 CSV / Excel | 不可用 | — |
| 保存历史记录 | **报表可查看的历史**：最近 5 天 | 5 天 | 只限制报表的查看范围，**原始单据一条不删、全部可以查看** |
| 高级数据分析 | 报表中的趋势图、商品 / 客户排行、毛利分析 | 不可用（仅显示今日 / 本月合计） | — |

**普通会员始终可以使用、不计次数**：开单（散客零售价）、查看和编辑已有商品、入库 / 出库 / 盘点、扫码、手机安装、AI 客服。

以上数字和开关都可以在平台后台修改（第 5 节）。

## 3. 次数限制规则（全部在服务端执行）

1. 每成功创建一个店铺 / 商品，对应的已用次数 +1（失败、校验不通过不计数）
2. 达到上限后，服务端拒绝创建（返回「已达到免费使用次数」），前端弹出升级窗口
3. 已创建的店铺、商品、单据**照常查看、编辑、使用**；不会因为达到上限或会员到期而删除或锁定任何已有数据
4. 删除商品不返还次数（防止反复删除绕过限制）；批量导入时，超出剩余次数的整批拒绝，并提示还能导入几个
5. 计数在数据库中按账号保存，并发创建也不会超出（加锁计数）
6. 升级成功后立即解除所有限制；高级会员不再计数
7. 员工在店铺里新建商品时，计入**店主**账号的次数（店铺的会员等级由店主决定）

## 4. 升级提示

达到上限或使用高级功能时弹出升级窗口（按触发的功能显示对应文字），以「项目创建」为例：

> **已达到免费使用次数**
> 你已经使用完当前普通会员的店铺创建额度。升级高级永久会员，即可解锁完整功能，不再受到普通会员次数限制。
> **¥29.9**　[立即升级]
> 一次性付款，永久享有高级会员权益，无需自动续费。

- 「立即升级」进入付款页：在线支付（接入真实渠道后）/ 扫码付款 / 激活码，开通流程和现在完全一样
- **透明展示**：套餐页显示「店铺 1 / 2、商品 2 / 3」等已用次数和全部限制；商品页、开店页在接近上限时提示剩余次数

## 5. 平台后台

可以修改（修改后立即生效，所有限制以服务端为准）：
- 普通会员：店铺上限、商品上限、报表历史天数
- 各项高级功能对普通会员是否开放（高级工具、高级模板、导出、高级数据分析）
- 高级永久会员价格（人民币、马币）
- 用户的会员等级（设为高级永久会员 / 普通会员，需填写原因，记录在变更记录里）

## 6. 技术方案

- 用户表增加：会员等级、成为高级会员的时间；新表「账号用量」（已创建店铺数、已创建商品数），用行锁计数
- 店铺的有效等级 = 店主是高级永久会员 → 高级；否则看店铺原有的订阅是否还在有效期内（第 7 节 A）；否则普通
- 套餐限制目前集中在 `PlanPolicy`，改为读取后台可修改的「会员配置」表
- 价格表增加「永久会员」一行；付款单、激活码、在线支付都支持开通永久会员（开通对象是账号，不是店铺）
- 现有的套餐权限检查（功能锁、升级提示组件）保留并改为新的文案和价格

## 7. 需要你决定

**A. 已经付费的用户怎么办？**（标准版 / 专业版订阅还在有效期内的店铺）
- 方案 1（推荐）：**有效期内照常使用**原来的功能，到期后不再续订，改为可以购买永久会员；原来的订阅和数据不受影响
- 方案 2：直接把现有付费用户升级为永久会员（对老用户最友好，但会少一部分收入）

**B. 已经卖出、还没兑换的激活码**（小红书上已售出的标准版 / 专业版 / 首月体验码）
- 推荐：照常可以兑换，按原来的天数开通对应的有效期（不变成永久）；以后小红书上只卖新的「永久会员激活码」

**C. 马币价格**：¥29.9 对应马币建议 **RM 19.9**（按现在约 1:1.5 的比例取整），请确认

**D. 普通会员的初始数字**：方案中「新建商品最多 3 个、报表历史 5 天」比现在的免费版（100 个商品、30 天报表）严很多。进销存软件里 3 个商品基本只够看一眼，可能来不及体验就离开。我按方案的数字实现，**建议上线前考虑改为商品 20 个、报表 30 天**（后台随时可改，不需要改代码）

**E. 首月体验 ¥1.99**：方案里没有，按方案取消（已兑换的不受影响）

## 8. 测试计划

- 后端：店铺 / 商品计数和上限（含删除不返还、导入整批拒绝、并发创建不超出）；员工建商品计入店主；高级功能接口全部拒绝普通会员（不只是前端隐藏按钮）；报表历史范围；升级后立即解除限制、新开店铺自动是高级；已有订阅有效期内照常使用、到期回到普通会员但数据完整；后台修改上限 / 开关 / 价格 / 会员等级立即生效且只有平台管理员能改；永久会员通过付款单、在线支付、激活码开通，重复开通不重复收费
- 端到端：普通会员建满商品 → 弹出升级窗口（文字、价格）→ 已有商品照常编辑 → 模拟支付升级 → 立即可以继续创建、高级功能解锁；套餐页显示已用次数；英文界面文字完整

## 9. 本阶段不做

按月 / 按年的新订阅（停止销售）、退款自动处理、会员转让、家庭 / 多人共享会员。
