# 11 · 多仓库 · 设计

> 阶段 15。

## 1. 要解决的问题

不少商户不止一个放货的地方：门店 + 仓库、两家门店、自家 + 寄存在批发市场的档口。现在系统只有一个库存数，不知道"门店还剩几个、仓库还剩几个"，也没法记录"从仓库拿 20 个到门店"。

## 2. 核心思路

- 每个商品在**每个仓库**有一个库存数；商品的总库存 = 各仓库之和（列表、报表、低库存提醒照旧用总数）
- 所有库存变动仍然只走 `InventoryService` 一个入口，只是多了"哪个仓库"；每条流水都记仓库
- **只有一个仓库时，界面完全不变**（不显示任何仓库选择），小店不会被打扰
- 进货成本仍按**商品**计算（各仓库共用一个移动加权平均成本），调拨不改变成本

## 3. 业务规则

| # | 规则 | 说明 |
|---|---|---|
| W1 | **默认仓库** | 每家店升级后自动有一个「主仓库」（现有库存全部归入）；默认仓库不能删除、不能停用，可以改名 |
| W2 | 新增 / 停用仓库 | 名称、地址、备注；停用前必须把库存调空（调拨走或盘点为 0）；停用后不出现在选择列表，历史流水保留 |
| W3 | **开单** | 选择出货仓库（默认取上次用的，没有则默认仓库）；库存不足按**该仓库**判断 |
| W4 | **采购收货** | 选择收货仓库 |
| W5 | **入库 / 出库 / 盘点** | 都针对某个仓库；盘点"把 A 仓库的数量调为 x" |
| W6 | **调拨** | 调拨单 `TF-20261109-0001`：从哪个仓库到哪个仓库、多个商品和数量；确认后立即生效（调出仓库减、调入仓库加，两条流水），总库存不变；调拨单不能修改，调错了再做一张反向调拨 |
| W7 | 取消销售 / 取消已收货的采购 | 库存回到**原来的仓库** |
| W8 | **套餐** | 多仓库为专业版，最多 5 个仓库。到期后：数据和库存都保留，主仓库照常使用；其他仓库**只能调拨出去**（把货调回主仓库），不能开单、入库、盘点，也不能新增仓库 |
| W9 | 负库存 | 店铺开启负库存时，各仓库都允许为负 |

### 一致性要求（测试必须覆盖）

- 任何时刻：`商品总库存 = 各仓库库存之和`，`某仓库库存 = 该仓库该商品所有流水之和`
- 调拨前后总库存不变；两个人同时从同一仓库调拨 / 开单不会超出（按仓库加行锁，多个商品按 id 顺序加锁）
- 其他店铺的仓库一律 404

## 4. 数据库（Flyway V14）

| 表 | 说明 |
|---|---|
| `warehouses` | id, tenant_id, name, address, notes, is_default, active, sort_order, created_at…；同店名称唯一 |
| `product_stocks` | tenant_id, product_id, warehouse_id, qty；(product_id, warehouse_id) 唯一 |
| `stock_transfers` / `stock_transfer_items` | 调拨单：单号、调出 / 调入仓库、备注、操作人；明细：商品、数量 |
| `stock_movements` | 新增 `warehouse_id`（NOT NULL）；新增类型 TRANSFER_OUT / TRANSFER_IN |
| `sales_orders` / `purchase_orders` | 新增 `warehouse_id`（出货 / 收货仓库） |

迁移：为每家店建「主仓库」→ `product_stocks` 按现有 `products.stock_qty` 生成 → 现有流水、销售单、采购单都归入主仓库。迁移后立即校验两个不变量。

## 5. 接口

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/warehouses` | 仓库列表（含每个仓库的商品种数、库存总量、库存价值） | 成员（店员看不到价值） |
| POST / PUT | `/warehouses[/{id}]` | 新增 / 修改；`POST /warehouses/{id}/deactivate` 停用 | 店主/管理员 |
| GET | `/products/{id}/stocks` | 某商品在各仓库的库存 | 成员 |
| GET | `/products?warehouseId=` | 商品 / 库存列表按仓库显示数量、按仓库判断缺货 | 成员 |
| POST | `/inventory/stock-in` 等 | 新增 `warehouseId`（只有一个仓库时可不传） | 店主/管理员 |
| POST | `/sales-orders`、`/purchase-orders/{id}/receive` | 新增 `warehouseId` | 原权限 |
| GET / POST | `/stock-transfers` | 调拨单列表 / 新建；`GET /stock-transfers/{id}` 详情 | 店主/管理员 |

## 6. 页面

| 页面 | 改动（只有一个仓库时都不显示） |
|---|---|
| **设置 → 仓库** | 仓库列表（库存总量、价值）、新增、改名、停用；非专业版显示升级说明 |
| 库存 | 顶部仓库切换（全部 / 各仓库）；商品行显示各仓库数量；入库 / 出库 / 盘点选择仓库；「调拨」按钮 |
| **调拨** | 新建调拨单（调出 → 调入、搜索或扫码添加商品、显示调出仓库可用数量）；调拨记录列表与详情 |
| 开单 / 采购收货 | 出货 / 收货仓库选择；商品行显示该仓库库存 |
| 商品详情 | 各仓库库存分布 |
| 库存流水、报表、Excel 导出 | 增加仓库列 / 按仓库筛选；报表「按仓库的库存」 |

## 7. 测试计划

- 迁移：已有数据迁移后两个不变量成立（测试库模拟升级前数据）
- 开单 / 收货 / 入库 / 出库 / 盘点按仓库生效；取消回到原仓库
- 调拨：总库存不变；调出仓库不足被拒；同一仓库不能调给自己；并发调拨与开单不超出
- 停用仓库：有库存时被拒；默认仓库不能停用
- 套餐：标准版不能新增仓库；专业版最多 5 个；到期后非主仓库只能调出
- 店员：能看各仓库数量、能开单选仓库，看不到价值、不能调拨
- 店铺隔离
- 端到端：新建「门店」仓库 → 主仓库调 20 个到门店 → 门店开单 3 个 → 门店剩 17、主仓库少 20、总数少 3 → 门店库存不足时提示

## 8. 本阶段不做

员工只能看 / 操作指定仓库、调拨在途状态（发货 → 签收两步）、各仓库单独的低库存预警值、各仓库单独成本、库位 / 货架管理。
