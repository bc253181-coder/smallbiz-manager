# 06 · 应收账款（赊账与收款）· 设计

> 阶段 10，专业版功能。完成后开始销售专业版（¥9.9/月 · ¥109.9/年；RM 6.9/月 · RM 69.9/年）。

## 1. 要解决的问题

批发、熟客生意经常"先拿货、月底结"。商户需要知道：**谁欠我多少钱、欠了多久、哪几张单没结清、什么时候收过钱**，并能打印对账单给客户核对。

## 2. 业务规则

| # | 规则 | 说明 |
|---|---|---|
| R1 | **只有选了客户的销售单才能赊账** | 散客必须当场付清（无法追讨）。开单时填「本次实收」，默认 = 应收；可填 0 到应收之间的金额 |
| R2 | **收款按客户记录** | 一次收款可以结清多张单。默认按开单时间**从早到晚**依次冲抵（先欠先还）；也可以在某张销售单上直接收这张单的款 |
| R3 | **不能多收** | 收款金额不能超过该客户当前欠款（本版本不做预收款/余额） |
| R4 | **收款可以作废，不能修改、删除** | 作废需填原因，自动撤回它冲抵的金额，相关销售单恢复为未结清。仅店主/管理员可作废 |
| R5 | **已收过款的销售单不能直接取消** | 需先作废相关收款，避免"单取消了钱却还挂着"。未收过款的赊账单可以直接取消，欠款随之消失 |
| R6 | **欠款 = 已完成销售单的（应收 − 已收）之和** | 已取消的单不计入 |
| R7 | **账龄按开单日期**计算：0–30 天、31–60 天、61–90 天、90 天以上 | 用于「逾期」提醒 |
| R8 | 权限 | 店员可以赊账开单、登记收款；作废收款、查看应收报表与对账单：店主/管理员 |
| R9 | 套餐 | 应收账款为**专业版**功能。到期或降级后：数据保留；销售单上的"已收/未收"仍可查看；不能新增赊账和收款，应收页面显示升级说明 |

### 一致性要求（测试必须覆盖）

- 任何时刻：`销售单.已收 = 开单时实收 + 该单所有有效冲抵之和`，且 `0 ≤ 已收 ≤ 应收`
- 任何时刻：`收款.金额 = 该收款所有冲抵之和`
- 两个人同时给同一客户收款，合计不能超过欠款（对客户的未结清销售单加行锁）
- 其他店铺的收款、对账单一律 404

## 3. 套餐升级与续费规则（必须先处理）

现状：购买**不同**套餐时，新套餐从"现在"开始，原套餐剩余天数会**丢失**。专业版开卖后会遇到：

| 情况 | 处理方式（建议） |
|---|---|
| 标准版还剩 N 天，购买专业版 | 专业版从现在开始，**剩余标准版天数按价格折算成专业版天数**追加：N × 6.99 ÷ 9.9（按月价折算，向下取整）。例：剩 20 天 → 追加 14 天 |
| 专业版有效期内，购买标准版 | **不允许**，提示"你当前是专业版，请续费专业版" |
| 专业版续费 | 从原到期日顺延（与现在的标准版续费一致） |
| 首月体验 | 只针对标准版，每店一次（不变） |

## 6. 页面

| 页面 | 内容 |
|---|---|
| 开单页 | 选了客户时显示「本次实收」（默认 = 应收），下方显示"本单欠款 ¥x，该客户累计欠款 ¥y" |
| 销售单详情 | 付款状态（已付清/部分付款/未付）、已收、未收、收款记录；「收款」按钮（只收这张单） |
| **应收账款**（新菜单） | 顶部：总欠款、逾期 30 天以上、本月已收；客户列表（欠款、账龄、最早欠款日）可搜索、按账龄筛选、导出；每行「收款」「对账单」 |
| 收款弹窗 | 客户、金额（默认 = 全部欠款）、方式、时间、备注；提交前预览"将冲抵哪几张单" |
| 收款记录 | 列表 + 作废（填原因） |

| 对账单 | 选择日期范围，可打印（A4），抬头显示店铺名称、电话、地址 |
| 仪表盘 | 店主/管理员新增「应收账款」卡片（总欠款、逾期金额） |
| 套餐页 | 标准版 / 专业版对比，购买专业版；显示剩余标准版天数的折算结果 |

## 7. 测试计划

- 赊账开单：已收/状态正确；散客赊账被拒；实收 > 应收被拒
- 收款先欠先还：三张欠款单，一次收款跨两张半；部分付款状态正确
- 指定单收款；超额被拒；作废后恢复；重复作废 409
- 已收款的单不能取消；未收款赊账单取消后欠款消失
- 并发：两人同时收款，合计不超过欠款
- 对账单：期初 + 销售 − 收款 = 期末，与手算一致
- 套餐：标准版不能使用；专业版到期后数据保留、只读；升级折算天数；专业版期间不能买标准版
- 店铺隔离：收款、对账单、应收列表
- 端到端：赊账开单 → 部分收款 → 作废 → 再收款 → 对账单数字核对

## 8. 本阶段不做

预收款/客户余额、信用额度、分期计划、自动催款提醒、应付账款（欠供应商的钱）——放到后续版本。
