# 18 · 快速发码 · 设计

> 已完成（2026-11-10）。发码台按小红书订单发码；快速发码不需要订单号，输入密码就能拿到一个码。

## 功能

- 网址 `/quick-code`，**不需要登录**。输入密码 → 点「生成激活码」→ 显示一个高级永久会员激活码，带「复制」按钮；再点一次就再出一个新码
- 每个码只能兑换一次；买家在「会员」页输入有效、没用过的码，就开通高级永久会员（和发码台发出的码一样）
- 码从发码台的库存里取；库存用完时，系统自动生成一批 50 个（批次名「快速发码自动补充」）再取，所以总能拿到码
- 取出的码在发码台的发码记录里，订单号显示为「快速发码」，可以按它搜索、查看状态（已发出 / 已兑换）、作废
- 发码台页面右上角有「快速发码（不用订单号）」按钮

## 安全

- 密码只放在服务器的 `deploy/.env`（`QUICK_CODE_PASSWORD`），不进代码库；不配置时页面关闭
- 同一 IP 15 分钟内输错 5 次后锁定 15 分钟
- 拿到密码的人可以无限生成永久会员码：密码不要发给别人；怀疑泄露时改 `.env` 里的密码并重启后端（`docker compose up -d backend`）

## 测试

- 后端：密码正确取码、每次不同、可兑换且只能兑换一次；输错 5 次锁定、其他 IP 不受影响；库存为 0 时自动补充
- 端到端：输错密码提示 → 输对生成两个不同的码 → 买家用第一个码开通永久会员
